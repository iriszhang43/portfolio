Laba Congee Recipe

Web Design • 2025

This project is a static, multi-panel recipe page designed with HTML and CSS.

Beyond presenting the conventional recipe content including ingredients, steps, and timing, this recipe page is designed to offer extra context that makes the cooking process more accessible, intuitive, and human-centered.

The goal is to create a layout that doesn’t just show instructions but also anticipates what the user might need in the moment, such as clarifying tricky steps, highlighting preparation details, and presenting information in a way that feels approachable and supportive.
